- O programa deve ser escrito em Python 3;
- O programa deve ler o arquivo config.json para obter as configurações necessárias;
- O programa deve gerar um baralho no final no formato PDF, contendo as cartas de acordo com as especificações do arquivo config.json;
- O programa deve gerar um pdf no final contendo lado a lado a parte da frente de cada carta e seu respectivo verso;
- O programa deve gerar um pdf para cada grupo de questionário, ou seja, um pdf para junior 1, outro para junior 2, outro para pleno 1, outro para pleno 2, outro para senior 1 e outro para senior 2;
- O programa deve usar para o fundo de todas as perguntas a imagem especificada background_card;
- O programa deve usar de verso das cartas a imagem especificada background_XXX sendo que para junior 1 usar jr1, para junior 2 usar jr2, para pleno 1 usar pl1 e para pleno 2 usar pl2, para senior 1 usar sr1 e para senior 2 usar sr2;
- Ele deve ler os jsons de perguntas e gerar uma carta apenas para cada pergunta, ou seja, se houver 10 perguntas no json, o programa deve gerar um baralho com 10 cartas;
- O número de questões em cada json é variável então o programa deve ser capaz de lidar com qualquer quantidade de questões, gerando um baralho com a quantidade de cartas correspondente;
- O programa deve ser capaz de lidar com perguntas que tenham mais de uma linha, ou seja, perguntas que sejam mais longas e precisem de quebra de linha para serem exibidas corretamente na carta;
- O programa deve indicar a resposta correta deixando a questão correta em negrito, ou seja, a resposta correta deve ser destacada em negrito para facilitar a identificação;
- O programa deve ser capaz de lidar com perguntas que tenham mais de 4 alternativas, ou seja, perguntas que tenham 5 ou mais alternativas devem ser exibidas corretamente na carta, sem que haja problemas de formatação ou legibilidade;
- As informações de fonte, tamanho da fonte, cor da fonte, posição do texto e outras configurações de formatação devem ser lidas do arquivo config.json para garantir que o programa seja flexível e possa ser facilmente adaptado a diferentes estilos de cartas;
- Os valores de tamanho da carta estão em milímetros e os valores de margem estão em pixels, então o programa deve ser capaz de converter corretamente as unidades para garantir que as cartas sejam geradas com as dimensões corretas e que o conteúdo seja posicionado adequadamente dentro das margens especificadas.
- A frente e o verso da carta devem ter o mesmo tamanho, ou seja, as dimensões da carta devem ser as mesmas para ambos os lados para garantir que o baralho seja consistente e que as cartas possam ser usadas de forma intercambiável.
